# Noir M. for VSCode

A dark, earthy color theme that brings the calm of moss-covered stone to your code. Deep void backgrounds paired with soft moss greens create a comfortable, low-contrast environment for long coding sessions.

## Features

- Deep void backgrounds that reduce eye strain
- Soft moss green accents for a natural, earthy feel
- Muted color palette designed for focus and readability
- Comprehensive syntax highlighting for all major languages
- Carefully balanced contrast ratios

## Installation

1. Open VSCode
2. Go to Extensions (`Ctrl+Shift+X` / `Cmd+Shift+X`)
3. Search for "Noir M."
4. Click Install
5. Go to **File > Preferences > Color Theme** (or press `Ctrl+K Ctrl+T`)
6. Select "Noir M."

## Color Palette

The theme is built on these core colors:

- **Moss**: `#7a9a7a` - Primary green accent
- **Stone**: `#5a6a5a` - Secondary muted accent
- **Earth**: `#9a8a5a` - Warm tertiary accent
- **Bark**: `#c04a3a` - Alerts and errors
- **Void**: `#0d0d0d` - Deep background
- **Cloud**: `#c6c6c6` - Primary text
